## FEATURED PROJECTS

### 01 — HR Employee Attrition Analysis

**Business Intelligence · Power BI · SQL · Python**

An end-to-end data analytics project exploring employee attrition patterns and workforce trends to support data-driven HR decisions.

**Dataset Overview**

| Metric | Result |
|:--|--:|
| Total Employees | 1,470 |
| Employees Who Left | 237 |
| Active Employees | 1,233 |
| Overall Attrition Rate | 16.12% |

**Project Highlights**
- Data cleaning and exploratory data analysis using Python.
- SQL queries to investigate employee attrition patterns.
- Interactive Power BI dashboard with KPI cards and visual analysis.
- Exploration of attrition by department, job role, overtime, income, and employee satisfaction.

**Tools:** `Power BI` `SQL` `Python` `Pandas` `Data Visualization`

[Explore Project →](https://github.com/YOUR_USERNAME/hr-employee-attrition-analysis)
